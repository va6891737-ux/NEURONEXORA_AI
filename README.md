# NeuroNexora AI 🧠

NeuroNexora AI is an AI-powered chat application.

## Features

- AI Chat Interface
- User-friendly web interface
- Python Flask Backend
- REST API
- Frontend and Backend integration

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask
- Flask-CORS
